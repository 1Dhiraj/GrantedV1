# `granted clawbot`

Legacy alias namespace kept for backward compatibility. It registers the same QR command as the top-level CLI, so `granted clawbot qr` accepts every [`granted qr`](/cli/qr) flag.

## Migration

Prefer the modern top-level command:

- `granted clawbot qr` -> `granted qr`
