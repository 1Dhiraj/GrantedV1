# Granted Amazon Bedrock Mantle Provider

Official Granted provider plugin for routing Amazon Bedrock Mantle models through OpenAI-compatible provider flows.

Install from Granted:

```bash
granted plugins install @granted/amazon-bedrock-mantle-provider
```

Use this plugin when your Bedrock deployment exposes Mantle-compatible model routing and you want Granted agents to address those models through the Bedrock Mantle provider.
